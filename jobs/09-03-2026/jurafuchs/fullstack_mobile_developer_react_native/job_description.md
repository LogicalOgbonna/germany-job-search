# Full-Stack Mobile Developer (React Native) (m/w/d)

## Job Title
Full-Stack Mobile Developer (React Native) (m/w/d)

## Company Intelligence
**Company:** Jurafuchs

Jurafuchs is the category leader for digital legal education in Germany with over 20,000 active users. Five universities (including University of Marburg and EBS Law School) use Jurafuchs as a supplement to legal education, and 25 top law firms use it to support their legal trainees. The company operates a mobile-first product built with React Native (mobile) and Next.js (web), backed by a Node.js/TypeScript backend on Azure. They are investing heavily in AI/RAG capabilities with Azure OpenAI and Azure AI Search. This is a high-impact role in a fast-growing legal tech company.

## The Role (Job Description)
As a Full-Stack Developer, you build production-ready features end-to-end — from UI/UX through APIs to the database — and are responsible for stability, performance, and security of web and mobile apps. You work closely with Product, Design, and Content teams and make pragmatic, data-driven decisions.

**Core Responsibilities:**
- Maintenance and expansion of web (Next.js) and mobile (React Native)
- Development and operation of Node.js services (REST)
- Integrations with third-party providers (Stripe, Firebase, Adjust, Meta/Google)
- Data modeling and efficient SQL queries (MySQL), migration management
- Search & AI: Building retrieval/research (Azure AI Search, Embeddings), connecting LLM-APIs (Azure OpenAI) including prompt/RAG-pipelines
- DevOps: IaC (Terraform), CI/CD, Observability, Security/Compliance (GDPR)

## The Ideal Candidate
**Technical Skills (Required):**
- Mobile: React Native (including Navigation, Platform-APIs), basic understanding of iOS/Android deployments
- Backend: Node.js/TypeScript, Express, Auth (JWT/OAuth), Caching (Redis), Rate-Limiting
- Databases: MySQL (Schemas, Indexes, Joins, Views), database migrations
- APIs/Integrations: Stripe (Subscriptions, Webhooks), Firebase/GA4 (Events/Conversions), App Stores (basic understanding)
- Testing: Jest, React Testing Library
- Git & Collaboration: Clean branching/PRs, Code Reviews, GitHub Actions

**Technical Skills (Search & AI):**
- Azure AI Search (Vector-Index, Skills, Indexer), Embeddings (OpenAI/Azure, local pipelines), ReRanking
- Cloud & Infra: Azure (App Service, Storage, Key Vault, Private Endpoints, RBAC), Terraform (Remote State, Imports)
- AI Integrations: Azure OpenAI Deployments/Provisioning-Models, Data-Zone-Concepts, PII-Filtering, Prompt-Security
