## The Role (Job Description)
- Architect and build production-grade frontends for AI agent products using React/Next.js
- Design interaction patterns for natural language and agent-driven user interfaces
- Brief and shape visual design with strong UX and layout sensibility
- Translate business requirements into product thinking
- Establish frontend best practices (component architecture, testing, code quality, CI/CD)
- Work at AI-development speed while maintaining production software quality standards

## The Ideal Candidate
**Experience:** Multiple years shipping real applications

**Technical Skills (Required):**
- Advanced React/Next.js expertise
- Frontend architecture: state management, performance optimization, component design, API integration, accessibility
- AI-assisted development proficiency (Cursor, Claude, Copilot, v0) — ability to prompt effectively, constrain outputs, review systematically
- Writing unit tests, version control, systematic output evaluation
- Clean architecture under time pressure

**Product Mindset:**
- Understanding of business context
- Ability to push back on unclear requirements
- Articulate UX opinions
- Strong layout and design sensibility

**Nice-to-Have:**
- Experience with conversational UIs, agent interactions, or natural language input patterns
