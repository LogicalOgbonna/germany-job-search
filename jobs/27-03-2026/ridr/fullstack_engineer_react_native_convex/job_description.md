# Fullstack Engineer (React Native / Convex)

## Job Title
Fullstack Engineer (React Native / Convex)

## Company Intelligence
**RIDR GmbH** is the digital infrastructure for mountain biking, offering structured learning paths for technique, setup, and repairs alongside tracking, spot maps, and community spaces. The company is founder-driven and headquartered in Germany. RIDR is building a gamified, community-driven mobile platform (ridr.bike) that blends education, social features, and GPS-based trail tools. The company prioritizes skills, mindset, and real ability over formal degrees, and operates with hybrid flexibility to enable meaningful work, personal growth, and sustainable performance.

## The Role (Job Description)
- Take deep technical ownership of the RIDR app, bridging design and engineering
- Transform Figma prototypes into polished mobile experiences using Expo/React Native for iOS and Android
- Architect Convex backend systems for gamified community features
- Build gamification backend systems including challenges, levels, and XP mechanics
- Develop social features: posts, likes, feeds, and community spaces
- Implement adaptive layouts with dark/light theme integration
- Design data models and real-time synchronization for GPS heatmap aggregation while maintaining privacy
- Oversee GitHub CI/CD and Expo EAS deployment processes
- Work closely with the Team Lead on technical direction

## The Ideal Candidate
### Required Skills
- **Tech Stack:** React Native, Expo, TypeScript
- **Backend:** Strong Convex experience (or deep experience with Firebase/Supabase with willingness to adapt)
- **Domain:** Experience building gamification systems (challenges, levels, XP) or social platform features (posts, likes, feeds)
- **Database:** Real-time social application database design skills
- **Mobile:** React Native styling, flexbox, and platform-specific nuances
- **Testing:** Device-based testing methodology and data integrity focus

### Preferred
- UI component system experience (shadCN UI, HeroUI)
- React Native Reanimated animation library knowledge
- Offline-first and sync strategy understanding
- Social feed algorithms and content moderation familiarity
- Location-based service architecture knowledge
