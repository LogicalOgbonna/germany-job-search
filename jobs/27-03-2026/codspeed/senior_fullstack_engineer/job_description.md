# Senior Full-stack Engineer

- **Job Title**: Senior Full-stack Engineer

- **Company Intelligence**: CodSpeed is a continuous performance optimization platform that helps engineering teams catch performance regressions before deployment, with sub-1% measurement variance. Founded in 2022 by Arthur Pastel and Adrien Cacciaguerra, the company is at seed stage with 1-10 employees and has offices in Paris (Nanterre) and New York. Backed by Techstars, Kima Ventures, and Better Angel. CodSpeed is trusted by major engineering teams at Cloudflare, Vercel, Mozilla, Pydantic, Astral (Ruff, uv), Apache, Prisma, LangChain, and ByteDance. The platform integrates into CI workflows (GitHub Actions, GitLab, Buildkite) to measure and block performance regressions in pull requests -- think "Codecov but for performance." The core technology uses a modified version of Callgrind (Valgrind tool) for CPU simulation, providing deterministic benchmarking with dedicated bare-metal "Macro Runners" for stable, isolated execution. Supports Rust, C++, Go, Python, and Node.js runtimes. CodSpeed is listed on the Partech and Techstars portfolio job boards, indicating strong VC network backing. Currently hiring across four roles (Senior Full-stack Engineer, Senior Systems Engineer, Senior/Lead AI Engineer, Graphic/UI Designer), signaling a significant growth phase.

- **Direct Application Link**: https://careers.codspeed.io/senior-full-stack-engineer (also accepts applications via careers@codspeed.io)

- **Work Model & Location**: On-site (Paris, France) or Remote (Europe) -- Full-time

- **The Role (Job Description)**:
  - Build and maintain the full-stack web platform that engineering teams use to monitor, analyze, and optimize code performance
  - Work across the frontend (React/Next.js) and backend (Node.js/TypeScript/GraphQL) to deliver end-to-end features
  - Build and maintain GitHub and GitLab integrations -- the core distribution channel through which CodSpeed surfaces performance insights directly in pull requests
  - Work with Rust data pipelines that process benchmarking and performance measurement data
  - Ship significant features to production with real ownership over the product
  - Collaborate with a small, high-impact engineering team (co-founders + engineers) where each person has outsized influence on the product direction
  - **Frontend stack**: React, Next.js, TypeScript
  - **Backend stack**: Node.js, TypeScript, GraphQL
  - **Data/Infrastructure**: Rust data pipelines, CI/CD integrations (GitHub Actions, GitLab, Buildkite)
  - **Core platform tech**: Callgrind/Valgrind-based CPU simulation, language runtime instrumentation

- **The Ideal Candidate**:
  - Senior-level full-stack engineer with strong React/Next.js experience
  - Proficient in Node.js and TypeScript across the stack
  - Experience with GraphQL APIs (design, implementation, and consumption)
  - Familiarity or experience with Rust, particularly for data pipeline work
  - Experience building integrations with developer tools, especially GitHub/GitLab APIs
  - Comfortable working in a small, early-stage startup environment where you own features end-to-end
  - Interest in or experience with performance engineering, benchmarking, or developer tooling
  - Based in Europe (for remote) or willing to work on-site in Paris

- **Application Strategy & Intel**:
  - This is a developer-tools company selling to engineering teams -- frame your experience around building products that developers use and love. Any experience with developer platforms, CI/CD tooling, or GitHub/GitLab integrations is high-signal
  - The Rust data pipelines requirement is notable -- even intermediate Rust experience or a strong willingness to learn will differentiate you. Highlight any systems-level programming experience
  - GraphQL is a core part of the stack, not just REST -- emphasize GraphQL schema design, resolvers, and client-side query management (Apollo, urql, or similar)
  - CodSpeed's customers are elite open-source projects (Pydantic, Ruff/uv, Prisma) and major tech companies (Cloudflare, Vercel, Mozilla) -- any open-source contributions or experience working with developer communities is worth highlighting
  - The team is tiny (under 10 people) and seed-stage -- emphasize autonomy, shipping velocity, and wearing multiple hats. This is not a role where you will be given narrow tickets; they want someone who can own entire features
  - Stock options are part of the compensation package -- at seed stage with this caliber of customers and investor backing (Techstars, Kima Ventures), the equity component could be meaningful
  - The company operates the HN "Who is Hiring" channel for recruitment, which signals a YC/HN-adjacent culture that values technical depth and open-source credibility
  - Apply directly via careers@codspeed.io with a tailored message -- small teams read every email. A brief note demonstrating you understand their product (performance regression detection in CI) will go further than a generic application
  - Competition for this role may be lower than typical European startup roles since it requires a somewhat unusual combination of React/Next.js + GraphQL + Rust -- if you can credibly cover all three, you are a strong match
