# Senior Full Stack Engineer — Vue.js, NestJS & TypeScript

**Job Title:** Senior Full Stack Engineer

## Company Intelligence

**Company:** Peter Park System GmbH
**Core Product/Mission:** Peter Park digitizes parking infrastructure using computer vision — replacing physical barriers (gates, ticket machines) with software-only solutions that use license plate recognition and seamless payment processing. The platform operates 500+ edge devices across Europe, processing thousands of parking and payment transactions per hour.
**Stage:** Scale-up phase — production system running at high throughput across European markets. Microservices architecture on AWS.
**Engineering Culture:** Fast-moving, pragmatic team that ships continuously to production. Engineers own features end-to-end, work with ML and DevOps colleagues, and collaborate closely with Design on UI/UX. MacBook M4 Pro + 37" curved monitor signal a serious engineering investment.
**Headquarters:** Munich, Germany

## The Role (Job Description)

As a Senior Full Stack Engineer at Peter Park, you will:

- Implement full-stack features end-to-end — from database schema through API to polished UI
- Collaborate with designers on UI/UX improvements across operator-facing and customer-facing surfaces
- Work alongside DevOps engineers and ML engineers on computer vision pipeline integration
- Deploy continuously to production on AWS (RDS, DynamoDB, S3, Lambda, Kubernetes)
- Shape and evolve the engineering culture as a senior team member
- Maintain high-throughput, resilient systems processing thousands of transactions per hour
