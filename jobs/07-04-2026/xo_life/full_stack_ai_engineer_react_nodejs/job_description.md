## The Role (Job Description)
As a Full Stack AI Engineer, you'll build the entire brite platform — from mobile-first React UIs to scalable Node.js backend services, with real-time features and cloud-native infrastructure.

**Responsibilities:**
- Build responsive, mobile-first UIs using React and React Native (Expo)
- Design and implement scalable backend architectures with Node.js and Express.js
- Develop cross-platform mobile applications via Expo
- Implement real-time features using WebSockets
- Deploy applications on AWS/GCP using Docker and Kubernetes
- Build and maintain CI/CD pipelines and data processing systems
- Collaborate closely with product managers and designers to translate requirements into features
