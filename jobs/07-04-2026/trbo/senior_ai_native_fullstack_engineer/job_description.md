## The Role (Job Description)

As a Senior AI-Native Fullstack Engineer at trbo, you will:

- Continuously develop and extend the trbo SaaS application with AI tooling deeply embedded in your development workflow
- Evaluate, prototype, and integrate generative AI/ML services and LLM APIs into platform features
- Lead and participate in code reviews and larger architectural initiatives
- Collaborate closely with product, design, and other engineering teams to prototype new features rapidly
- Take ownership of technical decisions affecting product quality and performance
- Work across the full stack: frontend (React), backend (PHP), and cloud infrastructure (GCP)
- Champion engineering best practices: testing, CI/CD, containerization, and distributed systems design

## The Ideal Candidate

**Required Tech Stack:**
- PHP (primary backend language) — strong, production-grade experience required
- React (frontend) — confident with component architecture, state management, and modern patterns
- Distributed systems and microservices architecture
- HTTP architecture, REST API design
- Containerization (Docker) and CI/CD pipelines
- LLM/generative AI API integration (OpenAI, Anthropic, or similar)
- Google Cloud Platform (GCP) — preferred but not mandatory

**Soft Skills:**
- Strong ownership and initiative — expected to drive features end-to-end
- Ability to evaluate and adopt new AI tools rapidly
- Collaborative mentality in cross-functional teams

**Experience:** 7+ years professional web development

**Language Requirements:** Fluent German AND English — both required
