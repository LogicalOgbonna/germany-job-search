# Senior Frontend Engineer (Remote)

## Company Intelligence

**HTTPie** is the maker of the popular open-source HTTP client (HTTPie CLI) and is building HTTPie for Web & Desktop, a modern API testing and collaboration platform. The team is small, developer-tools focused, and ships across web (Next.js) and desktop (Electron). They value developer experience, simplicity, delightful UX, and product craft. The product targets developers building/working with APIs.

## The Role (Job Description)

Help build high-quality features across HTTPie for Web & Desktop, the docs/website, and related properties.

**Day-to-day responsibilities:**
- Build user-facing features with a focus on top-notch user experience
- Implement complex React components with drag-and-drop, keyboard shortcuts, etc.
- Work on a shared React codebase deployed as Next.js and Electron apps
- Add real-time collaboration features across the product
- Improve application performance through profiling and other methods

**Tech Stack:**
- Frontend: TypeScript, React, Next.js, TailwindCSS, Electron, WebSocket
- Backend: Python, Terraform, AWS, Amazon Aurora, AWS Lambda, Django
- Tools: Vercel, GitHub, Linear, Slack, Notion, Figma, JetBrains IDEs

## The Ideal Candidate

- 5 years of software engineering experience
- Experience building React single-page apps
- Solid understanding of HTTP and modern APIs
- Solid understanding of modern coding, testing, debugging, and automation techniques
- Passion for developer tools and a sense for what makes them amazing
- Passion for simplicity, delightful UX, and an eye for design
- Good sense for when to choose robust vs. minimal solutions
- Strong communication, especially in writing
- Eagerness to learn and share

**Bonus:** TypeScript depth, distributed systems experience, technology product building, early-stage startup, open-source contributions, history of side projects, entrepreneurial spirit.
