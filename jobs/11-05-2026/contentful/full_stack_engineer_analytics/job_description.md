## The Role (Job Description)
Contentful is expanding its analytics capabilities tailored for marketers and content strategists. As a Full Stack Engineer on the Analytics squad, you will deliver AI interfaces, dashboards, and the supporting APIs on top of Contentful's data platform.

**Day-to-day responsibilities:**
- Build out AI agents, analytics dashboards, and the underlying APIs that support them
- Implement rich data interfaces using React, Next.js, Tailwind, and data visualization libraries (e.g., D3, Recharts, Visx — confirm internal preference)
- Develop and consume RESTful APIs in Node.js / TypeScript, integrating with existing analytics services
- Contribute to data pipelines that transform event data at petabyte-scale
- Ensure performance and usability in data-heavy interfaces through thoughtful architecture and loading strategies (virtualization, streaming, server components, caching layers)
- Collaborate cross-functionally with product, design, backend, frontend, and data teams to ship high-impact features quickly
- Operate in a "you build it, you run it" model with CI/CD, automated testing, and modern cloud tooling
