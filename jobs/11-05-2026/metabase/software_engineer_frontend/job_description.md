## The Role (Job Description)

Hiring for multiple frontend software engineer positions to advance the user interface of Metabase's BI product.

**Day-to-day responsibilities:**
- Build delightful, fast, opinionated UIs for data exploration and visualization
- Work on a large, complex React + Redux JavaScript codebase
- Write tests, give code review feedback, write thoughtful proposals
- Build complex interactive features (e.g., click-map filtering, data table interactions, annotations on charts)
- Augment visualizations (build features like annotations directly on data points)
- Build wayfinding tools to surface metrics/segments to the right users
- Build embedded analytics that match customers' own product styles

**Problem areas:**
- Lightning-fast data interaction (custom-region filtering, responsive data tables)
- Augmenting visualizations (annotations, data point exposure across dashboards)
- Wayfinding (surfacing metrics and segments to users)
- Embedded analytics (matching customer products visually)

## The Ideal Candidate

- Cares about crafting delightful user experiences (copy, details matter)
- Prior experience shipping non-trivial apps using React + Redux (or equivalent)
- Strong React + JavaScript knowledge
- Experience writing tests, giving good code review feedback, writing clear proposals
- Strong asynchronous communication and clarity
- Comfort with CS-y problems (data structures, performance, structure manipulation)
- Strong CSS / design system / component library experience
- Has worked on a large, complex JavaScript project
- **Nice to have:** data visualization (dc.js, d3.js), open-source contributions, Clojure interest
