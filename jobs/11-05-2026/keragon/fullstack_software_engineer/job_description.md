## The Role (Job Description)

Fullstack engineer building and scaling the core systems behind Keragon's no-code healthcare automation platform.

**What you'll do:**
- **Design and scale core systems:** workflow runtime engine, AI Copilot, API. Reliable, secure, performant as user base grows.
- **Build fullstack features end-to-end:** user-facing features in workflow editor UI connected to backend services through the API.
- **Enhance automation capabilities:** improve the workflow execution engine, contribute to the AI Copilot.
- **Drive integrations with SDK and CLI:** contribute to the connector SDK and CLI, occasionally build integrations.
- **Optimize performance and security:** deliver HIPAA-compliant, fault-tolerant solutions.
- **Collaborate cross-functionally:** turn requirements into clean, usable solutions with designers and customer-facing teams.
- **Incorporate AI:** incorporate AI tools and agentic workflows to streamline daily tasks.

**Tech Stack:** End-to-end TypeScript, language-agnostic mindset.
