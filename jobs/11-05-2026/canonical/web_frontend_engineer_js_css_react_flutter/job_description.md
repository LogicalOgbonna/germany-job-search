## The Role (Job Description)

Web Frontend Engineer building Canonical's portfolio of web properties (websites, console UIs, open-source documentation, customer dashboards) using modern web tech with TypeScript, React, CSS, and Flutter.

**Responsibilities (typical Canonical web frontend role):**
- Design, build, and maintain web applications across Canonical's product portfolio
- Build with React, TypeScript, modern CSS, and Vanilla Framework (Canonical's design system)
- Contribute to Flutter-based desktop UI work where overlap exists
- Engage with REST APIs and backend services
- Work with designers and product on accessibility, performance, and elegant UX
- Travel 2x per year for 1-2 week in-person team sprints

## The Ideal Candidate

- Outstanding academic record (CS/STEM degree strongly preferred)
- Web technology expertise: JS/TS, CSS, React
- Familiarity with Flutter (or willingness to ramp)
- Accessibility and performance mindset
- Linux/Ubuntu familiarity is a plus
- Strong written communication for an async, written-first culture
- Open-source contribution background welcomed
- Willingness to travel internationally 2x per year
