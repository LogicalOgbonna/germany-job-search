# Senior Frontend Engineer, Communications - 100% Remote - EMEA

## Company Intelligence

**Hostaway** is the AI-powered vacation rental management platform used by 20,000+ property managers worldwide. The Communications team builds messaging, inbox, and customer-interaction tooling at the heart of the platform's day-to-day workflow. Hostaway is a fully distributed EMEA engineering organization with team members across multiple European, Middle Eastern, and African cities. Engineering culture emphasizes cloud-native development, strong testing discipline, and direct cross-team collaboration.

## The Role (Job Description)

Senior Frontend Engineer on the Communications team, building real-time messaging and inbox experiences for property managers and guests across the Hostaway platform.

**Day-to-day responsibilities:**
- Build and maintain React + TypeScript UIs for messaging, inbox, customer interactions
- Implement state management with Redux / Context API patterns
- Integrate with backend systems via REST APIs, webhooks, and WebSockets
- Write tests with Jest, Cypress, and Playwright
- Collaborate with product, design, and backend engineers in an async EMEA setup
- Contribute to cloud-native frontend infrastructure

## The Ideal Candidate

- **6+ years** of frontend development experience
- Strong proficiency in React, TypeScript, JavaScript, CSS, HTML
- Solid state management experience (Redux, Context API, or equivalent)
- Hands-on with REST APIs, webhooks, and/or WebSockets
- Experience with testing frameworks (Jest, Cypress, Playwright)
- Cloud-native development familiarity
- Strong async written communication
