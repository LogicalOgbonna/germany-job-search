## The Role (Job Description)
Build and maintain fullstack features for AMBOSS's medical platform on the Software Platform team. Work across frontend (React/TypeScript) and backend (PHP, Go) with Kubernetes and modern CI/CD tools.

### Responsibilities
- Build fullstack features across frontend and backend
- Work with JS/TS/React on the frontend
- Develop backend services with Go, Python, or PHP
- Deploy and manage applications on Kubernetes
- Maintain and improve CI/CD pipelines

## The Ideal Candidate
### Required
- Solid understanding of at least one backend language (Go, Python, or PHP)
- Frontend experience with JS/TS/React
- Knowledge of Kubernetes and modern CI/CD tools preferred

### Tech Stack
- JS/TS/React (frontend), PHP, Go (backend), Kubernetes, CI/CD
