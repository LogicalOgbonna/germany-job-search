# Application Answers - Galvany Senior Frontend Engineer

## How do you use AI in your everyday work or personal life?

AI is deeply embedded in how I work, both as a tool I build with and one I use daily to move faster.

At Genentech, I co-built a production RAG chat widget using OpenAI's GPT models, LangChain, and the Vercel AI SDK, where users could connect their own data sources and query them conversationally in real time. That project gave me hands-on experience designing prompts, managing context windows, and integrating streaming AI responses into a polished UI.

More recently, I built OurNigeria (ournigeria.ng), an AI-powered platform for Nigerian budget transparency, entirely from scratch. I designed and implemented a multi-agent system using the Mastra framework, with 5 specialized agents handling intent classification and domain-specific RAG-powered analysis over 700+ government documents. I used AI tools throughout the build: Claude and ChatGPT for architecture decisions and debugging, GitHub Copilot for boilerplate and test generation, and Cursor for fast iteration on complex TypeScript logic.

Day-to-day, I use AI assistants as a thinking partner: rubber-ducking architecture, generating test scaffolding, reviewing my own code for edge cases, and prototyping UI ideas quickly before committing to implementation. It has meaningfully cut the time between idea and working code.

I am genuinely excited to bring this into a product like Galvany's, where frontend work involves real data complexity and the team is clearly willing to move fast.
