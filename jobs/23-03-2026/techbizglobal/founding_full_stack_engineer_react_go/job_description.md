## The Role (Job Description)
As a founding engineer, you will help build the core platform from the ground up. This is a high-impact, high-autonomy role working directly with a technical CEO and CPTO. Responsibilities include:

- Developing frontend applications using React and TypeScript
- Building backend services with Go (Gin framework)
- Designing cloud solutions on AWS (EC2, Lambda, S3, SQS, SNS)
- Managing databases including PostgreSQL, Neo4J, Redis, Elasticsearch
- Containerizing applications using Docker and Kubernetes (EKS)
- Automating processes via Bash/Python scripting
- Designing and maintaining RESTful and gRPC APIs
- Implementing caching, messaging queues, and event-driven architectures
- Building AI agent systems with LLMs, RAG, and embeddings (AWS Bedrock, LangChain)
- Monitoring and optimizing performance, reliability, and scalability
