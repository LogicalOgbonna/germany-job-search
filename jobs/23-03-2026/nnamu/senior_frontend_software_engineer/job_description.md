## The Role (Job Description)
You will architect and develop the frontend applications powering nnamu's AI-driven negotiations platform. Day-to-day responsibilities include:

- Building React-based features and creating modular, reusable components
- Architecting scalable, performant frontend applications
- Optimizing for performance and accessibility
- Conducting code reviews and maintaining code quality standards
- Mentoring junior engineers
- Collaborating with product and design teams
