## The Role (Job Description)
This is a technical leadership role combining hands-on development (majority of time) with team management. Day-to-day responsibilities include:

- Leading, coaching, and developing a team of full-stack engineers
- Designing and implementing robust, scalable web applications
- Ensuring clean, maintainable, testable code meeting engineering standards
- Guiding architecture decisions and long-term technical planning
- Enhancing application speed and system reliability
- Mentoring engineers and supporting career growth
- Conducting code reviews and fostering constructive feedback culture
- Contributing to technical documentation and cross-team knowledge sharing
