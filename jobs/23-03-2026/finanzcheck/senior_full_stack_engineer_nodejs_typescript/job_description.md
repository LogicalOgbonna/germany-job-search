## The Role (Job Description)
You will join the **cross-selling tech team**, building scalable services that drive additional revenue streams. Day-to-day responsibilities include:

- Operating and building distributed NodeJS/TypeScript services on Kubernetes infrastructure
- Creating and maintaining React/TypeScript user interfaces for both customer-facing and internal applications
- Designing asynchronous, event-driven communication using AWS SNS and SQS
- Implementing real-time WebSocket features with Redis adapters (socket.io)
- Managing third-party integrations and external system connections
- Establishing inter-service contracts using Protobuf and Zod validation
- Implementing OAuth, JWT, and identity provider authentication flows
- Full ownership of products ("you build it, you run it, you own it")
- Participating in team decision-making on goals, technical choices, and timelines

## The Ideal Candidate

**Required Technical Skills:**
- Expert-level Node.js and TypeScript for distributed applications
- Strong event-driven architecture and asynchronous messaging experience (SNS, SQS)
- Extensive TypeScript/React frontend development, particularly in B2C conversion contexts
- Secure authentication/authorization implementation (OAuth, JWT, OIDC)
- Real-time communication and distributed systems patterns (WebSockets, socket.io, Redis)
- AWS RDS experience (MySQL, Postgres)
- GitHub Actions, AWS, Kubernetes, and Terraform proficiency
- End-to-end ownership capability with stakeholder alignment skills

**Nice to Have:**
- Grafana stack familiarity (Loki, Grafana, Tempo, Mimir/Prometheus)
- Customer communications or sales advisory domain experience

**Tech Stack:** Node.js, TypeScript, React, MySQL, Postgres, AWS (SNS, SQS, RDS), GitHub Actions, Terraform, Kubernetes, Docker, Protobuf, Zod, OAuth/JWT, WebSockets, socket.io, Redis
