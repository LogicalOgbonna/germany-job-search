## The Role (Job Description)
You will join a guild of 85 frontend engineers building the financial management platform used by 550,000+ customers. Day-to-day responsibilities include:

- Crafting new features for customers within a Cross-Functional Team
- Participating in a major migration of 1.1 million lines of code from Ember.js to React
- Suggesting and spearheading technical improvements
- Collaborating with Product, Design, and other Tech stacks
- Contributing to Qonto's custom design system and UI library
- Peer review and maintaining high quality standards

## The Ideal Candidate

**Required Technical Skills:**
- Minimum 3 years professional experience using React.JS (Ember.JS experience also valued)
- Strong HTML and CSS proficiency (pure CSS — they do NOT use Tailwind or CSS frameworks)
- Meticulous attention to detail — "great work is the accumulation of many small things done right"
- Clear, organized, concise, and accurate communication

**Tools & Culture:**
- Unlimited access to AI tools: Claude Code, Cursor, Copilot, Dust, Notion AI
- Part of a 85-engineer frontend guild with 33% non-male representation
- Pair-programming and React training provided
