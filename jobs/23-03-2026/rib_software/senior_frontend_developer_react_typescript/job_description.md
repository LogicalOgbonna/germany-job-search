## The Role (Job Description)
You will work on enterprise construction/building technology frontend applications. Day-to-day responsibilities include:

- Developing new features and improving existing components
- Integrating user feedback and resolving technical challenges
- Converting designs into performant, maintainable code with focus on usability and scalability
- Collaborating with interdisciplinary teams (developers, designers, product owners)
- Applying modern technologies and frontend best practices
- Contributing to quality assurance through automated testing, including AI-assisted approaches
- Participating in architecture decisions and technical evolution
- Fostering open feedback culture and knowledge sharing

## The Ideal Candidate

**Required Technical Skills:**
- Strong experience with modern React versions and core principles
- REST API expertise, preferably with TanStack Query and Axios
- Deep HTML/CSS knowledge for precise design implementation
- Proficiency with data visualization libraries (Highcharts, Handsontable)
- Understanding of scalable, maintainable application architecture
- Automated testing experience, ideally with AI-powered test generation
- Solid knowledge in state management, Git, and frontend fundamentals
- AI/AI-agent comprehension preferred
- C1-level German AND English proficiency (both required)

**Soft Skills:**
- Team-oriented with strong communication and feedback skills
- Passion for continuous learning

**Tech Stack:** React, TypeScript, HTML/CSS, REST APIs, TanStack Query, Axios, Highcharts, Handsontable, Git
