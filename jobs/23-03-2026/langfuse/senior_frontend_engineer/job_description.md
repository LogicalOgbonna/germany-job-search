# Senior Frontend Engineer

## Job Title
Senior Frontend Engineer

## Company Intelligence
**Langfuse** is the most widely adopted open-source LLM engineering platform, helping engineers and enterprises build and run LLM applications at scale. The company was founded in Berlin and is backed by Y Combinator, Lightspeed Venture Partners, and General Catalyst (raised a $4M seed round). In January 2026, Langfuse joined ClickHouse to accelerate growth. The platform has 23,232+ GitHub stars, 23.1M+ SDK installs per month, and 6M+ Docker pulls. The team is small and focused, operating out of San Francisco and Berlin with team members spread across Europe. This is a high-growth, high-impact opportunity at one of Europe's most exciting open-source devtools companies.

## The Role (Job Description)
You will own much of the public-facing Langfuse user experience end-to-end. This is a senior frontend engineer role at an early-stage company building the leading open-source devtools platform. Past projects you would lead include:

- Improving the frontend application architecture
- Building self-serve dashboards to generate insights into billions of LLM executions
- Creating performant table components with a focus on usability and fast rendering times
- Implementing advanced filtering and search interfaces for complex datasets
- Owning and showcasing your work publicly (open source)

## The Ideal Candidate

**Required Technical Skills:**
- 3+ years in frontend development
- Strong in React, TypeScript, and modern CSS — clean, maintainable component code
- Deep care about performance — profiling React renders, debugging layout thrashing, knowing when to virtualize, memoize, or restructure
- Experience with high-performance web applications handling large datasets
- Strong state management and data fetching patterns knowledge

**Nice to Have:**
- Performance optimization experience
- ML/AI background
- Notable side projects or startup experience
- CS or quantitative degree

**Soft Skills:**
- Hard worker who thrives in a small, accountable team
- Intuitive UI/UX thinking

**Tech Stack:** React, TypeScript, Next.js, Express, Shadcn, Prisma, tRPC, Tailwind, PostgreSQL, ClickHouse, Python, S3, Redis
