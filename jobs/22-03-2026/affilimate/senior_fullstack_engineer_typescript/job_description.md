## The Role (Job Description)
This is a product-oriented fullstack engineering role. You will build new features end-to-end based on customer research, working across the entire stack — from React UI to Node.js backend services. The codebase is fully TypeScript.

### Key Responsibilities
- Build new features end-to-end based on customer research
- Build tools that ingest and display large volumes of analytics data
- Optimize and scale existing workflows
- Work on the customer-facing API
- Enhance features with AI capabilities
- Integrate 3rd party APIs
- Maintenance, refactoring, and fixing issues reported to the Support team
- Participate in product research and talk to users

## The Ideal Candidate

### Required Skills
- 7+ years of prior professional experience
- Strong technical background, ideally from an early to mid-stage startup
- Very strong understanding of data structures (data aggregation and transformation is a huge part of the job)
- Strong TypeScript skills — comfortable with generics, union types, and working in a TypeScript-first codebase
- Experience with React — a big part of the job involves building and improving the UI
- Product-oriented mindset — love talking to users and participating in product research
- Ability to work autonomously on projects

### Tech Stack
TypeScript (frontend + backend), React, Node.js, Analytics/Data Platform
