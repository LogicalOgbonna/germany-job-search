## The Role (Job Description)
As a Senior Frontend Engineer, you will take strong ownership of delivering high-impact features end-to-end — from technical discovery and solution design to implementation, testing, rollout, and monitoring in production. You will build complex, maintainable React components and application flows using TypeScript and modern frontend architecture principles.

### Key Responsibilities
- Own frontend feature delivery end-to-end from discovery through production monitoring
- Translate product requirements into scalable technical solutions
- Build complex, maintainable React components using TypeScript
- Write comprehensive unit and end-to-end tests
- Contribute to architectural discussions on frontend structure and performance
- Collaborate closely with Product and Design teams
- Mentor less experienced engineers and foster engineering excellence
