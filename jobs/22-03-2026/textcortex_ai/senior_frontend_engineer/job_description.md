## The Role (Job Description)
TextCortex AI seeks a senior frontend engineer to lead UI development for their AI platform. The role emphasizes ownership, innovation, and collaboration within a high-performing startup culture. You will be responsible for designing and implementing intuitive, responsive interfaces that serve millions of users.

### Key Responsibilities
- Design and implement intuitive, responsive interfaces using React and TypeScript
- Own features end-to-end from concept through release
- Write clean, testable code and conduct thorough peer reviews
- Optimize performance and scalability across the platform
- Collaborate with backend engineers on seamless API integration
- Improve frontend tooling and developer experience
- Mentor junior developers and foster engineering excellence
- Work on Chrome extension development

## The Ideal Candidate

### Required Skills
- 5+ years building modern web applications with React
- Expert-level TypeScript proficiency
- Deep understanding of state management, component design, and performance optimization
- Strong debugging and problem-solving abilities
- Proficiency with Git, CI/CD pipelines, and testing frameworks
- Product-first mentality with user-centric approach
- Ownership-driven and proactive mindset

### Nice-to-Have
- Node.js experience
- REST/GraphQL API experience
- Cloud infrastructure experience
- Chrome extension development

### Tech Stack
React, TypeScript, State Management (hooks, context), Chrome Extension APIs, CI/CD, AI coding tools (Cursor, GitHub Copilot)
