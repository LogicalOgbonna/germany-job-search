## The Role (Job Description)

As a (Senior) Software Engineer at Tacto, you join one of the early engineering team members shaping architectural decisions and tackling significant technical challenges while working directly with the founders on a high-impact, core team position.

### Responsibilities

- Make system architecture and tool selections for B2B SaaS applications
- Define domain models and business logic for enterprise applications
- Develop backend structures, APIs serving multiple customers, and frontend components
- Own technical decisions regarding frameworks, tools, data models, and scalability
- Lead code reviews, mentor team members, and establish engineering quality standards
- Document progress and communicate technical approaches proactively
- Work across the full stack, contributing to both frontend and backend
