# Web Developer - React

## Job Title
Web Developer - React

## Company Intelligence
**SOFHA GmbH** is a Berlin-based software company established in 1981, with approximately 60 international employees. SOFHA develops software products and technologies for high-performance image processing solutions based on industry standards such as Adobe PostScript and Adobe PDF Print Engine. As an OEM partner of leading professional production printer manufacturers, SOFHA develops intelligent print workflow solutions covering high-resolution image data handling and accurate color management. The company has a long track record of stability (40+ years) and specializes in enterprise printing technology. Their office is located close to Gesundbrunnen, in the center of Berlin with excellent public transportation connections.

## The Role (Job Description)
As a Web Developer - React, you will:
- Implement secure web applications for printer management and print-job management
- Work with a modern React-based frontend stack
- Build modular, component-based architecture
- Participate in software design and code reviews
- Work within a monorepo/workspace setup using npm workspaces
- Contribute to CI/CD pipelines via GitLab

## The Ideal Candidate
**Required:**
- Strong proficiency in React and TypeScript
- Solid knowledge of HTML5 and CSS3
- Experience with Vite as build tool
- Familiarity with React Query and Zustand for state management
- Experience with Material UI component library
- Git version control proficiency
- npm workspaces / monorepo experience
- Node.js familiarity
- GitLab CI/CD experience
- Understanding of modular architecture patterns

**Tech Stack:** React, TypeScript, HTML5, CSS3, Vite, React Query, Zustand, Material UI, Git, npm workspaces, Node.js, GitLab CI/CD
