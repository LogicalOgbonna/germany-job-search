## The Role (Job Description)
As a Software Engineer - React, you will:
- Develop web applications using JavaScript/TypeScript and React (or other modern frameworks like Angular or Vue)
- Conduct and participate in code reviews to maintain high code quality
- Collaborate with teams and customers on technical requirements
- Evaluate and advocate for new frontend technologies
- Develop a "T-Shape profile" for continuous professional growth
- Handle CSS styling and UI implementation using preprocessor languages like Sass

## The Ideal Candidate
**Required:**
- Solid JavaScript foundation with TypeScript familiarity
- Strong React knowledge and ecosystem experience (Redux, etc.)
- CSS proficiency including preprocessor languages (Sass)
- Practical experience with agile development methods (Scrum, Kanban, XP, TDD)
- Good communication and presentation skills in **German and English** (German required)
- Completed university degree with above-average performance and/or several years of relevant professional experience
- Active participation in company initiatives

**Tech Stack:** JavaScript, TypeScript, React, Redux, CSS/Sass, Angular/Vue (alternatives)
