# Lead Fullstack Engineer (React/Next.js)

## Job Title
Lead Fullstack Engineer (React/Next.js)

## Company Intelligence
**PHONT** is an early-stage AI startup on a mission to "bring subtitles to life." They use AI to capture tone, emotion, and tempo of speech, then turn those cues into animated subtitles. This is a **founding-stage opportunity** — you would be one of the first engineering hires, with significant ownership over the codebase and technical direction. The company operates at the intersection of AI, creative media, and accessibility tech. Working language is English.

## Direct Application Link
**Email:** career@phont.ai

No formal cover letter needed. Send: CV/LinkedIn, project portfolio/GitHub links, optional technical challenge notes.

## Work Model & Location
- **Hybrid-friendly** — work remotely or from Frankfurt office
- Flexible hours ("as long as the work gets done")
- Berlin/Germany-based candidates welcome

## The Role (Job Description)
- **Migrate prototype to production-grade Next.js 14** application with scalable architecture
- Develop type-safe APIs (**tRPC/REST/GraphQL**) interfacing with Python audio analysis backend
- Build **emotion-driven subtitle animations** with real-time rendering
- Establish CI/CD pipelines and infrastructure-as-code
- Set technical standards and **mentor future team members**
- Own significant parts of the codebase and serve as the "glue" between frontend and audio-analysis backend

## The Ideal Candidate
**Required:**
- **3+ years** with React.js, Next.js, and TypeScript
- Backend API development and database experience
- HTTP/WebSocket protocol fluency
- **Creative coding** background (Canvas, WebGL, SVG animations)
- Proven prototype-to-production experience
- CI/testing pipeline familiarity
- Cloud deployment knowledge (AWS/Azure)

**Nice-to-have:**
- Audio/video processing experience
- Animation libraries (Framer Motion, GSAP)
- Design system contributions
- German language (not required)

**Tech Stack:** Next.js 14, React, TypeScript, tRPC/REST/GraphQL, Python (backend), Canvas/WebGL/SVG, AWS/Azure
