The company provides algorithmic trading and market-making services for digital assets, with hubs in London, Brussels, Singapore, and Paris. Keyrock operates at the intersection of traditional finance and crypto, building sophisticated trading infrastructure and analytics platforms. ## The Ideal Candidate
### Required Skills
- Full stack web development experience with frontend and backend proficiency
- Modern frontend frameworks: **React**, Vue, or similar
- Backend development, preferably **Rust** or typed languages
- HTTP and RESTful API design knowledge
- Relational/NoSQL database experience with schema optimization
- Git workflows, CI/CD, and automated testing familiarity
- Product-oriented mindset with collaborative communication

### Preferred Skills
- Fintech/crypto application experience
- Secure coding and OAuth2/OpenID Connect awareness
- Data visualization libraries (D3.js, Recharts)
- Observability tools: Grafana, Prometheus, Datadog
- Kubernetes and containerization experience
- Financial datasets and analytics dashboard experience

### Tech Stack
- **Frontend:** React, Vue, Shadcn component library
- **Backend:** Rust (preferred), typed languages
- **DevOps:** Kubernetes, GitLab CI, Docker
- **Observability:** Grafana, Prometheus, Loki, Datadog
