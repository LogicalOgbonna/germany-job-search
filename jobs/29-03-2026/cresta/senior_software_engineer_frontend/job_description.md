## The Role (Job Description)
As a Senior full-stack engineer with a front-end focus, you will:
- Collaborate with product and design teams to define requirements and architect solutions
- Design software architecture for complex web applications
- Write high-quality frontend and backend code
- Implement synchronous and asynchronous design patterns
- Scale distributed applications for high-volume, reliable performance
- Enhance engineering productivity and integrate CI/CD tools, testing frameworks, and monitoring systems
- Build 24/7 reliable, multi-tier applications

## The Ideal Candidate
**Required:**
- Deep expertise in modern frontend frameworks including React, Vite, and Node.js
- Experience applying these tools to complex, production web applications
- Proficiency in API design with protocols like WebSockets, REST, and RPC
- Database schema design knowledge with query optimization skills
- Application performance monitoring and observability experience

**Tech Stack:** React, Vite, Node.js, WebSockets, REST APIs, RPC, CI/CD tools
