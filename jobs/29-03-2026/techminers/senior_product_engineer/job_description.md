# Senior Product Engineer

## Company Intelligence
**TechMiners GmbH** is a Berlin-based startup building automated machinery for the next generation of M&A due diligence. The company leverages AI as a force multiplier in engineering, using tools like Claude Code and Cursor as core development tools. They operate remote-first and are at an early, high-growth stage.

## Direct Application Link
https://techminers.bamboohr.com/careers/25

## Work Model & Location
**Remote-first** — Berlin, Germany. Must have a valid German work permit with primary residence in Germany.

## The Role (Job Description)
- Own core product features from the database to the React UI while ensuring system reliability
- Actively use and chain agentic AI tools (Claude Code, Cursor) to accelerate development cycles
- Collaborate with CTOs to translate business requirements into technical solutions
- Maintain a scalable, secure architecture prepared for AI integration
- Build TechMiners ONE, the automated machinery for M&A due diligence

## The Ideal Candidate
**Required:**
- 5+ years of production-level engineering experience with Django expertise
- Advanced proficiency with AI-native development and agentic tool orchestration (beyond basic copilot usage)
- Product-focused mindset prioritizing user problems over complex code
- Valid German work permit with primary residence in Germany
- Remote-first work capability

**Tech Stack:** Python, Django, React, Claude Code, Cursor
