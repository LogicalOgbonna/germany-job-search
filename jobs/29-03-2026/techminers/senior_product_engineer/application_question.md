I built OurNigeria (ournigeria.ng), an AI-powered platform that lets Nigerian citizens query government budget data in plain English or Pidgin. The core challenge was making 700+ budget documents across 37 states searchable and analyzable through natural conversation.

A single query like "how much did Lagos spend on healthcare vs education?" requires understanding intent, retrieving data from multiple documents, and synthesizing comparative analysis with charts. A generic RAG pipeline couldn't handle this because budget queries span different analytical domains that each need specialized retrieval and prompting.

I built a multi-agent system using the Mastra framework with 5 specialized agents: a Router that classifies intent through three stages (keyword scoring, LLM classification with caching, inferred fallback), then delegates to domain-specific analysts (Budget, Corruption, GovSpend, Impact). Each agent runs a hybrid RAG pipeline combining pgvector similarity search with BM25 full-text search, merged via Reciprocal Rank Fusion and reranked with Cohere. The full stack is NestJS + Next.js + PostgreSQL 16 with Prisma, managing 708K+ vector embeddings. I own every layer, from database schema to the React frontend that renders 22 auto-generated chart types from AI responses.

Key learnings: multi-agent routing is worth the complexity when domains genuinely differ, but the classification layer needs to be fast and cacheable or it kills latency. The three-stage intent classification (keyword first, LLM second, fallback third) was the key insight. Hybrid search (vector + BM25 + reranking) dramatically outperforms pure vector search for structured data like budget tables. And SSE streaming with keepalive heartbeats is essential for real-time chat UX when AI responses take several seconds to generate.
