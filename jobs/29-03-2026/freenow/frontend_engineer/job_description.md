## The Role (Job Description)
As part of a highly skilled cross-functional team in the Supply domain, you will:
- Break down user stories into actionable frontend tasks
- Write and maintain clean, modular, and scalable code
- Implement responsive and accessible UI components based on design mockups
- Review code submitted by peers to ensure consistency, quality, and adherence to best practices
- Receive feedback on your own code and make necessary adjustments
- Write and maintain unit tests for frontend components
- Attend daily standups and participate in planning sessions to estimate and commit to tasks

**Team Structure:** Cross-functional team comprising Frontend Engineers, Backend Engineers, Product Designer, Product Manager, and a technical Engineering Manager.
