# Fullstack Engineer, Shopify

## Company Intelligence
**Talon.One** is a Berlin-based loyalty and promotions platform that provides the most powerful incentives engine, unifying loyalty, promotions, and gamification into one holistic platform. The company serves over 250 of the world's most-loved brands including Adidas, Sephora, and Carlsberg. Backed by enterprise-grade security and scalability, Talon.One is well-established in the promotion management space.

**On-site** — Berlin, Germany. Candidates must already be based in Berlin or willing to relocate. 90 days annual work-from-abroad flexibility is offered.

## The Role (Job Description)
As a Fullstack Engineer with a front-end focus on the Shopify team, you will:
- Develop React/TypeScript front-end applications for Shopify merchants
- Build and maintain embedded Shopify apps including setup flows, configuration UIs, and diagnostics
- Integrate with Shopify APIs using GraphQL and REST standards
- Collaborate with backend engineers working in Rust/Go on API design and integration
- Ensure code quality, maintainability, and accessibility standards across the codebase
- Work closely with product managers and solution teams to deliver reliable, intuitive integration experiences

## The Ideal Candidate
**Required:**
- Professional experience with React and TypeScript
- Strong modern front-end fundamentals: state management, component design, accessibility
- Familiarity with Shopify APIs, particularly Admin and Storefront GraphQL APIs
- E-commerce integration experience
- Ability to collaborate effectively with backend engineers

**Nice-to-Have:**
- Production experience building embedded Shopify apps
- Rust or Go knowledge
- Webhook and event-driven workflow expertise
- Checkout, pricing, or promotion flow exposure

**Tech Stack:** React, TypeScript, Redux, CSS modules, Cypress, Go, Kubernetes, Google Cloud, PostgreSQL
