# Senior Frontend Engineer

## Job Title
Senior Frontend Engineer

**HiveMQ GmbH** is the Industrial AI Platform helping enterprises move from connected devices to intelligent operations. They specialize in MQTT-based messaging infrastructure and distributed edge-to-cloud architecture, powering IoT and industrial connectivity for marquee clients including **Audi, BMW, Eli Lilly, and Siemens**. HiveMQ is a well-established player in the IoT middleware space, headquartered in Germany with a remote-friendly engineering culture. The company positions itself at the intersection of industrial IoT and AI, enabling enterprises to build intelligent, connected operations at scale. Their cultural pillars are **Effortless, Empowered, Relentless**, emphasizing simplicity, ownership, and relentless boundary-pushing.

## The Role (Job Description)
This role focuses on delivering a simple, intuitive, and high-quality UI/UX experience for HiveMQ's platform products. Day-to-day responsibilities include:

- Architecting, implementing, and maintaining frontend applications
- Building reusable UI components that establish company-wide standards
- Refactoring existing codebases and optimizing APIs
- Developing new features with strong UI/UX consideration
- Collaborating with Product Managers to create customer value
- Contributing to developer experience, code quality, and CI/CD pipelines
- Learning MQTT, distributed systems, and IoT fundamentals
- Participating in peer code reviews and maintaining high engineering standards

The position involves collaboration with full-stack engineers and requires some backend familiarity alongside deep frontend expertise.

## The Ideal Candidate

**Required:**
- 5+ years architecting and delivering modern web frontends
- 5+ years hands-on with **TypeScript, JavaScript, SCSS, CSS, HTML**
- Profound **React** experience with reactive state management
- Build tools expertise (**webpack, turbopack**)
- Testing knowledge (**Cypress, Selenium, Jest**)
- GitHub version control proficiency
- Web security familiarity (**OWASP, OAuth2, TLS**)
- Solid understanding of AI-assisted development technologies
- Kanban agile methodology experience
- CI/CD pipeline experience
- Excellent communication skills

**Nice to Have:**
- UI/UX concepts and web design knowledge
- A/B testing experience
- Feature-toggles implementation
