# Fullstack Senior Software Engineer — Nextio

## Job Title
Fullstack Senior Software Engineer

## Company Intelligence
**Nextio GmbH** is an early-stage Berlin fintech infrastructure company building a new SaaS layer for **interbank communication** across Europe. The product underpins reliable, secure, regulated data exchange between banks and fintechs — a space normally dominated by SWIFT and legacy bank rails. Nextio is targeting that gap with a modern, API-first, event-driven platform. The role description signals a company that has graduated past zero-to-one and is now hardening for scale: standards, mentoring, and "engineering excellence culture" are explicit asks. Office is at Kurfürstendamm in Berlin with a remote-friendly hybrid policy. Engineering culture is small-team, high-ownership, regulated-environment-aware (security, auditability, financial compliance) — so expect strong opinions on rigor and SLA discipline.

## The Role (Job Description)
This is a senior individual contributor role with explicit tech-leadership scope. You will:
- Architect and evolve a secure interbank communication platform end-to-end.
- Build core infrastructure for reliable, auditable data exchange between financial institutions.
- Define long-term technical direction and establish engineering standards (testing, CI/CD, observability, on-call).
- Lead distributed-systems design for high-load reliability, security, and regulatory traceability.
- Deliver complex capabilities end-to-end, balancing speed against the rigor required of a financial platform.
- Mentor senior engineers and cultivate the engineering-excellence culture as the team grows.

## The Ideal Candidate
**Required Tech Stack**
- APIs (REST and GraphQL) with authentication / authorization patterns (JWT, OAuth2).
- Event-driven systems (Kafka, WebSockets).
- PostgreSQL — schema design, query optimization, migrations.
- ORMs such as Prisma.
- Cloud platforms — GCP (Cloud Run, Cloud Functions).
- CI/CD pipelines via GitHub Actions.
- Docker and Kubernetes.

**Experience**
- 8+ years building and operating production systems.
- Track record owning architecture and leading other senior engineers.

**Bonus Skills**
- Go, Java/Kotlin.
- Microservices at scale.
- Fintech background; prior experience in regulated environments (SWIFT, PSD2, BaFin context).
