# Senior Full-Stack Developer (Ruby / React.js) — GOhiring

## Job Title
Senior Full-Stack Developer (Ruby / React.js) f/m/d

## Company Intelligence
**GOhiring** is the leading software company for **automated job posting and recruiting analytics** — recruiters use the product to manage the entire job-posting process in one place, from data-driven multi-posting campaigns to candidate-journey analytics. Operates as a remote-first, small but experienced engineering org. The codebase is mid-life: a small cluster of Ruby microservices on Heroku/AWS with **a deliberate frontend transition from custom JS + Ember.js toward React** — that transition is part of why this role is open. Engineering culture is mature: 100% code review, CI/TDD, kanban via ZenHub on GitHub, and "we don't like putting out fires" framing. Funding model is profitable / cash-flow funded (B2B HR tech), so the team optimizes for sustainable code quality over hype-cycle velocity. Twice-yearly company offsites + twice-yearly direct-team meetups are part of the offer.

- Be a creative problem solver — implement impactful, sustainable solutions to complex, varied challenges.

- Proactively monitor and optimize for security and performance.
