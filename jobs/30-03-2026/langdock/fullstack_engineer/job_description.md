## The Role (Job Description)
This is a full-stack engineering role with heavy AI infrastructure focus:

- **AI Engine Development**: Ship features for the AI engine that orchestrates model releases through a unified abstraction layer, including prompt caching, automatic failover across deployments, and middleware handling provider-specific quirks
- **Streaming Systems**: Build resumable streaming infrastructure allowing users to disconnect and resume mid-response, with retry logic that continues from exact stopping points
- **Workflow Automation**: Develop agents that pause for human input, extract structured outputs, and chain actions across integrations using Redis-coordinated execution
- **Advanced Infrastructure**: Work with Model Context Protocol (MCP), agent-to-agent communication, and retrieval-augmented generation (RAG) pipelines
- **Product Ownership**: Own AI system implementation end-to-end, managing rendering performance, perceived latency, and novel UI paradigms for AI-native software
- **Cloud Infrastructure**: Design and maintain deployments across Azure, AWS, GCP, and bare metal servers with security and reliability requirements
