# Senior Frontend Engineer - Escudo

## Company Intelligence

**Feedzai** is a pioneering AI company in fraud prevention and anti-money laundering solutions, trusted by major financial institutions worldwide. The Escudo Team builds the design system foundation that allows Feedzai to disrupt the financial crime industry with speed and consistency. By providing a robust, cloud-first, and flexible design system, they enable product teams to focus on solving complex financial risk problems rather than reinventing UI components. Feedzai is known for a supportive and inclusive culture with numerous growth opportunities.

## Work Model & Location

**Flex/Remote** - Portugal (EU-based). Options include: primarily office-based (4-5 days/week), flexible (2-3 days/week), primarily remote (1-2 days/month), or fully remote for employees not near global offices.

## The Role (Job Description)

As a Senior Frontend Engineer on the Escudo team, you will:

- Architect and build highly reusable, accessible (WCAG), and performant React components that serve as the standard for all Feedzai products
- Collaborate with designers to implement pixel-perfect interfaces
- Create documentation and tooling via Storybook for developer adoption
- Establish testing strategies (unit and component tests) for quality assurance
- Consult with product teams on UI pattern implementation
- Serve fellow engineers and designers as your primary customers

## The Ideal Candidate

**Required:**
- BSc/MSc in Computer Science or related field
- 4+ years with modern JavaScript (ES6+), HTML5, and advanced CSS
- Deep React and TypeScript expertise
- Demonstrated experience architecting, building, or significantly contributing to a Design System (not just using one)
- Solid knowledge of Web Accessibility standards (WCAG) and semantic HTML
- Experience with testing frameworks (Jest, React Testing Library) and visual regression tools (e.g., Chromatic, Cypress)
- Experience with Storybook or similar documentation platforms
- A "Service Mindset" or "Platform Mindset", enjoying helping other developers succeed

**Nice-to-Have:**
- npm package management and release lifecycle experience

**Tech Stack:** React, TypeScript, JavaScript (ES6+), HTML5, CSS, Storybook, Jest, React Testing Library, Chromatic, Cypress, npm
