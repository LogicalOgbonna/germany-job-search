**Protofy GmbH & Co. KG** is a digital product agency based in Hamburg that builds mobile apps and web applications for clients. They work in small cross-functional teams of 2-10 people from different disciplines. Remote-first since 2019 with strong emphasis on work-life balance and flexibility. The company invests in employee wellbeing through monthly coaching sessions, flexible sabbaticals, and family-friendly policies.

## The Role (Job Description)

Create mobile apps or web applications in teams of 2-10 people from different disciplines. Design and implement new features collaboratively across the full product lifecycle.

**Responsibilities:**
- Create mobile apps or web applications in cross-functional teams
- Design new features with product managers and UX designers
- Implement new features in collaboration with backend and operations colleagues
- Solve bugs, improve performance of websites and mobile apps
- Participate in organizational development through dev roundtable discussions
- Estimate project efforts to support project management
- Deploy features after code review through CI/CD pipelines to production

## The Ideal Candidate

**Required:**
- Senior-level frontend development experience
- React ecosystem expertise (for web projects)
- Flutter experience (for app projects)
- Application design experience
- Ability to guide a team in setting up applications from scratch

**Experience Level:** Senior (5+ years expected based on role seniority)
