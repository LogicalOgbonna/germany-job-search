# Senior Software Engineer - Frontend (Lisbon)

## Company Intelligence

**Datadog** is a leading monitoring, security, and analytics platform for cloud-scale applications. The company provides full-stack observability for infrastructure, applications, logs, and security, serving thousands of enterprise customers worldwide. Datadog is publicly traded (NASDAQ: DDOG) and is one of the most highly valued cloud software companies globally. Their Lisbon engineering office is a growing hub with multiple frontend teams working on core observability products.

## Work Model & Location

**Hybrid** - Lisbon, Portugal. Datadog operates as a hybrid workplace to ensure employees can create a work-life harmony that best fits them.

## The Role (Job Description)

As a Senior Software Engineer (Frontend), you will:

- Use React and TypeScript to streamline the flow of data from platform to user
- Enable seamless pivots from one view to the next across the platform
- Work on complex frontend challenges for thousands of customers with huge sets of data
- Work on exciting scalability and performance challenges
- Break down complex features into distributable engineering tasks and rollout plans
- Design and deliver features that have direct impact on thousands of users
- Experiment with and advocate for new systems, design patterns, and tooling
- Own meaningful parts of the service while improving performance and addressing scalability limits

## The Ideal Candidate

**Required:**
- Expert in JavaScript/TypeScript and modern frontend frameworks such as React
- Master of the JavaScript ecosystem, aware of the latest trends with frontend technologies
- Knowledge of how to use design patterns to create simple and reusable components for complex UIs
- Familiarity with data structures and algorithms, profiling and optimization
- Value code simplicity, performance, and attention to detail
- Experience with modern frontend build tools, bundlers, and CI/CD workflows

**Nice-to-Have:**
- Experience building internal tools, component libraries, or design systems for large engineering organizations
- Deep experience with bundlers (e.g., Rspack, esbuild, Lage)

**Tech Stack:** React, TypeScript, JavaScript, modern frontend build tools, CI/CD pipelines

## Application Strategy & Intel

Datadog has multiple frontend teams in Lisbon (Platform & Developer Experience, Product Engineering, Security Platform, Data Visualization). Apply through the Datadog careers page. The company values engineers who can work at scale and handle complex data visualization challenges. Multiple senior frontend positions are open, so consider which team aligns best with your interests. Highlight experience with performance optimization and large-scale data-driven UIs.
