## The Role (Job Description)
- Take ownership of complex frontend features end-to-end, from scoping and architecture to polished, high-quality delivery
- Push the boundaries of what is possible with modern frontend technologies
- Build pixel-perfect interfaces matching design specifications
- Collaborate closely with Product, Design, and Backend teams
- Maintain high code quality standards across the frontend codebase
- Evolve and contribute to the component library and design system

## The Ideal Candidate
**Required:**
- 5+ years professional frontend engineering experience, ideally in fast-paced startup or high-growth environments
- Deep expertise in TypeScript, React, and modern frontend tooling
- Proven track record of shipping high-quality user-facing products
- Component library or design system contribution experience
- Professional CSS, TailwindCSS, and semantic HTML proficiency
- Exceptional attention to visual detail and a strong eye for design
- Strong communication and ownership capabilities
- Strong portfolio or GitHub profile demonstrating quality work

**Tech Stack:** TypeScript, React, Tailwind CSS, Firebase/Firestore, CSS
