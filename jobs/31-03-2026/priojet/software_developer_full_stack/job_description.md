## The Role (Job Description)

Build across the full stack, from backend APIs to mobile and web frontend user interfaces.

**Responsibilities:**
- Architect and implement new backend features using NestJS/Node with TypeScript
- Develop React Native mobile applications (using Expo.io)
- Maintain GraphQL APIs and integrate third-party services
- Contribute to technical decisions on app architecture and development priorities
- Collaborate with product teams on UI/UX quality
- Build scalable, reusable software solutions and documentation

## The Ideal Candidate

**Required:**
- 3+ years as a Full Stack Software Engineer
- Backend: Python, NodeJS, Ruby, or Go
- Frontend: React, ReactJS, or React Native
- B.Sc or M.Sc in Computer Science or similar
- Database knowledge (PostgreSQL, MySQL, NoSQL)
- DevOps: Docker, CI/CD, Git workflows, cloud services (AWS, Azure, Google Cloud)
- Security best practices understanding
- Agile development experience
- Fluent English (German is a plus)
