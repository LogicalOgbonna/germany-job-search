## The Role (Job Description)

As a Senior Frontend Engineer, you will:

- Develop and maintain responsive, user-friendly landing pages, websites, and web applications
- Collaborate with designers to convert mockups into pixel-perfect, functional interfaces
- Create clean, efficient, and scalable HTML, CSS, and React code
- Optimize site performance, speed, and search engine visibility
- Ensure compatibility across browsers and devices (desktop, tablet, mobile)
- Integrate APIs and backend data sources into frontend systems
- Identify and resolve development issues post-launch

## The Ideal Candidate

**Required:**
- 5+ years frontend development experience with 1-2 years React.js expertise
- Proficiency in HTML, CSS, and JavaScript
- Knowledge of responsive design and mobile-first principles
- Understanding of UX/UI design principles and designer collaboration
- Git version control and collaborative development experience
- SEO best practices for frontend implementation
- RESTful API integration knowledge
- Attention to detail with problem-solving orientation
- Strong communication and teamwork abilities

**Nice-to-Have:**
- Design tool familiarity (Figma, Sketch, Adobe XD)
- Backend technology basics (Node.js, Express, databases)
- Headless CMS platform experience (Contentful, Strapi)
- WCAG accessibility standards knowledge

**Tech Stack:** React.js, HTML, CSS, JavaScript, RESTful APIs, Git
