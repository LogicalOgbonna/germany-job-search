## The Role (Job Description)

As a Senior Frontend Engineer, you will be a pivotal contributor to the product's success. Responsibilities include:

- Leading enterprise-level frontend architecture design using React and TypeScript
- Using AI tools (Copilot, Cursor, LLMs) to accelerate development velocity
- Establishing React patterns and best practices to reduce technical debt
- Translating business objectives into scalable technical roadmaps with cross-functional teams
- Mentoring junior and mid-level engineers on architecture and performance
- Conducting rigorous code and architectural reviews
- Optimizing performance across devices and network conditions
- Championing emerging patterns like Server Components

## The Ideal Candidate

**Required:**

**Tech Stack:** React.js, TypeScript, Vite, HTML5, ES6+, Next.js, Remix, MUI, Tailwind CSS, TanStack Query, React Testing Library, Vitest
