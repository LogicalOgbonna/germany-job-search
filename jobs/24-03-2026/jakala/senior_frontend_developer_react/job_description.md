## The Role (Job Description)
You will develop customer platforms innovatively and according to current standards within product teams. Day-to-day responsibilities include:

- Developing customer-facing platforms with React and Next.js
- Working closely with UX/UI design and backend development to create outstanding user experiences
- Integrating AWS Cloud Services with the frontend
- Integrating content from headless CMS (Contentful)
- Ensuring high code quality and applying Clean Code principles
- Contributing to design systems and frontend architecture
- Working across personalization, data, SEO, and analytics features

## The Ideal Candidate

**Required Technical Skills:**
- Deep knowledge of JavaScript/TypeScript, React, and Next.js with successful project experience
- Clean Code principles and high code quality standards
- Broad technical experience beyond core work area: personalization, data, SEO, analytics
- Contentful CMS integration experience
- AWS cloud services familiarity
- Design systems experience
- Agile development methods

**Tech Stack:** React, Next.js, JavaScript, TypeScript, AWS, Contentful CMS, Design Systems
