# Senior Fullstack React & Backend Engineer (m/f/x)

## Job Title
Senior Fullstack React & Backend Engineer (m/f/x)

## Company Intelligence
**Staffomatic** is a Hamburg-based SaaS company building a workforce management platform for shift planning and team scheduling. The product helps businesses manage employee schedules, availability, and time tracking. Staffomatic operates as a mid-sized product company with an experienced Hamburg-based engineering team. The company culture emphasizes transparency, innovation, and distributed team collaboration. Notable perks include annual team retreats (Cape Town) and regular knowledge-sharing sessions.

Hybrid/Remote — Hamburg, Germany (St. Pauli office) or fully remote within Germany

## The Role (Job Description)
You will actively shape the workforce management platform alongside an experienced team. Day-to-day responsibilities include:

- Leading the Ember.js to React migration effort (major technical initiative)
- Maintaining and advancing a Rails-based REST API
- Designing and implementing product features end-to-end
- Evaluating and refactoring existing code continuously
- Contributing to architectural and technical decisions
- Participating in agile planning and delivery processes

## The Ideal Candidate

**Required Technical Skills:**
- 5+ years with React and modern frontend development (state management, component architecture, hooks, performance, E2E testing)
- Production-grade React application experience
- Ruby on Rails expertise including APIs and business logic
- Complex feature design with non-trivial business requirements
- Modern frontend tooling: Tanstack-Router, Tailwind, Vite/Webpack, REST APIs
- AI technologies and AI-powered development tools familiarity
- Native German speaker, fluent English (both required)

**Tech Stack:**
- **Frontend:** React, Tailwind, Tanstack-Router, Capacitor.js
- **Backend:** Ruby on Rails, MySQL, Redis, Memcached, RSpec, GitHub
