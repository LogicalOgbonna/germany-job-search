As a startup, the culture emphasizes ownership, rapid iteration, and cross-functional collaboration across backend, AI, and robotics teams. ## The Role (Job Description)
You will own and evolve the gauss.chat frontend architecture, building the browser-based interface for a robotics platform. Day-to-day responsibilities include:

- Building scalable UI structures with clean modular boundaries in an expanding codebase
- Integrating authentication systems (OAuth, AWS Cognito, JWT)
- Implementing real-time features via WebSockets and Server-Sent Events for AI insights
- Creating 3D visualization components using Three.js and Meshcat
- Optimizing rendering performance in real-time contexts
- Maintaining UI systems with Material-UI (Joy) and Tailwind CSS
- Developing testing strategies and enforcing code quality standards
- Collaborating across backend, AI, and robotics teams
