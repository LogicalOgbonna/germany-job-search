# Software Engineer, Full Stack, Observability (Europe)

## Company Intelligence

**Vercel** is the company behind Next.js and the leading frontend cloud platform, powering the web's biggest sites (including Walmart, Washington Post, and Notion). Vercel's mission is to enable developers to build a faster web. The Observability team is responsible for building first-class monitoring and debugging tools that give developers deep insight into their application performance. Vercel is a well-funded, high-growth company (Series D, valued at $2.5B+) with a strong open-source culture and a reputation for engineering excellence.

## The Role (Job Description)

Join the Observability team to take Vercel's observability offerings to the next level. You will enable better insight into applications and their performance during all stages by implementing first-class observability tooling. Key responsibilities include:

- Designing and implementing scalable web services, applications, and APIs
- Developing and maintaining Observability products (logging, tracing, monitoring dashboards)
- Collaborating closely with partners and cross-functional teams
- Designing software system architecture for scale
- Developing and maintaining internal software tools
- Troubleshooting, bug fixing, and identifying bottlenecks
- Improving software efficiency and writing technical documentation

## The Ideal Candidate

- 5+ years of relevant work experience
- Strong proficiency in JavaScript/TypeScript/Go
- Advanced programming skills in TypeScript, Node.js, and React
- Experience with modern frontend development tools and frameworks
- Solid understanding of columnar databases (Clickhouse, Tinybird)
- Experience processing large quantities of data at scale, using messaging systems or streaming services
- Experience contributing to or participating in open source projects
- Familiarity with frontend frameworks, performance profiling, and optimization for web applications
- Good experience with NoSQL databases

## Tech Stack

TypeScript, Node.js, React, Go, Clickhouse, Tinybird, NoSQL databases, streaming/messaging systems
