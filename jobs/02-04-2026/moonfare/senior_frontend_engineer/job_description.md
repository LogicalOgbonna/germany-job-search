## The Role (Job Description)

As a Senior Frontend Engineer, you will be instrumental in translating complex private-market and regulatory logic (KYC, capital calls, eligibility rules) into clear, intuitive user interfaces.

### Core Responsibilities

- Lead architectural decisions for scalable, cross-platform components
- Design features across web and native interfaces
- Write maintainable code and conduct code reviews
- Optimize performance, accessibility, and cross-platform compatibility
- Develop reusable UI components for design systems
- Collaborate with product, design, and backend teams
- Manage data-heavy dashboards and portfolios while maintaining responsiveness
- Securely integrate with backend/third-party services (authentication, KYC, payments)
- Maintain design consistency across multiple products and legacy systems
